IMPORTANT PRODUCTION NOTE
The image tiles in this pack are extracted from a generated contact sheet, so they are
small placeholder crops, not separate original high-resolution source photographs or
true transparent PNG/SVG assets. Some crops may include edge artifacts from the sheet.
Use them for layout prototyping only; replace photographic placeholders with licensed,
high-resolution originals before production. The generated UI screenshots are references,
not functional page assets. The supplied logo is preserved as-is in brand-reference.

Suggested Next.js public folder mapping
Copy the contents of this folder into:
  public/assets/urbanmaali/

Recommended production follow-up
1. Obtain/export the logo as a clean transparent SVG or PNG.
2. Replace placeholder photo crops with licensed originals sized for their display use.
3. Recreate icons and botanical ornaments as editable SVGs for crisp scaling.
4. Add alt text and optimize photographs to WebP/AVIF during build.
5. Confirm usage rights for every final image before deployment.
